# 雨棚下的空座

数学小故事 · 先看问什么，再看估大还是估小

适合三年级亲子共读。六章，可停下来翻图、说一说，约15～20分钟；故事不判分，不锁章节。

【封面图】雨中的露天电影院：小美、雨棚、银幕与座位；座椅仅作场景示意，不逐个代表实际座位。

## 第一章　银幕上的第一滴雨

星期六傍晚，小美来到山坡上的露天电影院。银幕还没展开，一只蜗牛先爬上了白布，留下亮亮的一道线，像替电影画了片头。

今晚的电影讲一粒种子怎样长成树。小美盼了好几天。她带来一块坐垫，角上绣着一片歪歪的叶子，准备坐在最前面，看看种子的第一条根从哪里钻出来。

【图1】雨棚里有四排座位：四排各98个；400人每人需要1座。色条示意，不按数量比例。

可她刚放下坐垫，一滴雨就落在叶子上。第二滴落在鼻尖，第三滴砸在空铁桶里，“当”的一声。山后的云挤过来，连晚霞也只剩下细细一条。

放映员把白布抱住，抬头看了看天。旁边有一座旧雨棚，里面已经摆好四排座位，每排98个。今晚领了座位票的观众一共400人，大人孩子都算在内，一人要有一个座位。

【图2】人数与座位要一一对应：400人 → 需要400座；比较：98×4座 ↔ 400座。色条示意，不按数量比例。

“把银幕搬进去吧！”小美赶紧卷起坐垫。

放映员却没有马上动。他指指正在收伞的人：“先得知道，大家能不能都坐下。不能让最后来的人抱着湿伞站一整晚。”

【图3】先听清问题：大约多少？ → 估算；够不够？ → 比较界线。位置示意，不按数值比例。

小美掏出铅笔，差点先数起棚顶的横梁。数到第三根，她停住了：横梁有几根，能回答大家坐不坐得下吗？她在纸上画了四排座位，又在旁边画了一长串小小的圆脑袋。

“每人要一个座位，400人就需要400个座位。”她说，“要拿四排座位的总数，和需要的400个座位比。”

雨打在棚顶上，像一把豆子滚来滚去。小美把纸挪到干处。她希望答案是“够”，但纸上的问号还没有答应。

## 第二章　纸上多出来的座位

98离100很近。小美想，每排先看成100个，四排就是400个。她在纸上写下“大约400个”，心里一下轻松了。

“那就刚好——”话到嘴边，她看见最外一排的末端空着两小段。那里只有地板，没有椅子。四排都是这样。

【图1】98更靠近100：98离100差2；98离90差8。位置示意，不按数值比例。

她拿铅笔把一排画长一点，补上两个虚线小框。纸上凑到了100个，地上却并没有多出两把椅子。小美看着虚线，明白自己是把座位数估大了。

“等等，我刚才在每排里，想象着多放了两个座位。”小美蹲下来，摸摸那块空地，“四排都多放了，才有400个。真的座位一定不到400个。”

【图2】每排补出想象的2座：98实有 + 2想象 = 100；4排共想象 2×4 = 8座。色条示意，不按数量比例。

放映员正抱着银幕走到棚口，听见这句话，又把白布放到长凳上。雨水沿着卷边往下滴，他用空桶接住，没让水碰到白布。

小美把四排末尾的虚线框圈起来。每排少2个，四排一共少8个。要让400人都有座位，得再添8个，不能拿一句“大约”把这8个空位填上。

【图3】从估大数找回实际：400 - 8 = 392座；392 < 400，还差8座。位置示意，不按数值比例。

她在原来的那句话后面加了一个小尾巴：“大约400个，实际比400个少。”再算清楚，是392个。

“差一点，也还是差。”她轻轻拍了一下自己的坐垫，好像在安慰它，“先别急着挑最前面的位置。我们得找椅子。”

【轻互动】收起或恢复每排想象的2个座位，再观察实际与估计的区别。

> 翻图：四排都用“98个实有座位＋2个想象座位”表示。四排假想凑满是100×4＝400；实际少了2×4＝8，所以98×4＝392。问够不够时，先看出不到400就能判断不够；问差多少时，再求出8。

## 第三章　屋檐下的一小张纸

雨棚旁有间工具房。小美记得，去年收秋时，里面摆过折叠凳。她跑到门口，发现门没锁，却被一把歪倒的扫帚卡住了。

她轻轻扶起扫帚，门开了一条缝。里面满是干草的气味，一只蜘蛛把网织在高高的窗角，倒像挂着一把透明的伞。

【图1】借凳纸上的数：4排，每排98座；400人需要400座。色条示意，不按数量比例。

墙上钉着借用记录：折叠凳上次搬到菜园，今天傍晚送回。桌上只剩一张画纸，画着空椅子，椅背上还画了一朵花。

小美把纸翻过来，打算给搬凳子的人留句话。她先写“雨棚大约有400个座位”，想了想，又划掉了。这句话只告诉人一个大概数，看不出为什么急着借凳子。

【图2】差额告诉我们借多少：已有392座 + 借8座；补齐后400座。色条示意，不按数量比例。

她重新写：“400位观众，每人一个座位。雨棚四排，每排98个，还差8个。凳子送回来后，请先借8个。”

写完她又回看了一遍。400说的是人数，98说的是每排的座位，4说的是排数，8说的是缺少的座位。每个数都有事情可做，没有一个只是为了把纸填满。

【图3】两个问句不同：大约多少：约400座；够不够：392 < 400，不够。位置示意，不按数值比例。

门外传来小车声。她冲出去，却只看见装着雨衣的车停在屋檐下。折叠凳还没回来。

小美有些失望。远处的白幕被风鼓起，像一口深深的叹气。放映员朝她招手：“先别淋雨。附近的人送来了一些干毛巾，可以让大家擦擦椅子。”

## 第四章　多估了，还够吗

毛巾装在几只布袋里，共有6袋，每袋69条。每条都叠成方方的一小块，像安静的白面包。小美先把其中一条搭到湿凳面上，抹掉一串水珠。

放映员问：“400人，要是每人发一条，够不够？”

【图1】每袋多想一条：69条 → 看成70条；6袋共多想6条。色条示意，不按数量比例。

小美把69看成70，六袋便是420条。刚才补座位的虚线框又在她脑子里冒出来。她没有马上说够。

“420比400多，可420也是我多想出来一点的。”她说，“我得知道多想了多少。”

【图2】把多想的拿走：估计420条 - 6条；实际414条。色条示意，不按数量比例。

每袋把69看成70，多想了1条。6袋，一共多想了6条。从420条里拿走这6条，还有414条，仍比400条多。这样才真的够。

她在纸上画了三个小记号：400、414、420。414在400的右边，离420很近，却并不是420。

【图3】比较界线：400需要 < 414实际 < 420估大；修正后仍超过400，够。局部数轴，位置按数值比例。

“刚才座位往大了想，才刚到400，所以实际不够。这次毛巾往大了想，超过了400；把多想的拿走以后，还超过400，才知道够。”

放映员把毛巾篮放在入口处。雨声里，第一位进棚的观众接过毛巾，擦干了自己的椅子，也擦了旁边的椅背。

小美又望向工具房。她真希望毛巾能变成凳子，但那显然是另一部电影里的事。

【轻互动】展开多想的6条，比较修正前后与400的关系。

> 翻图：69×6先看成70×6＝420，是估大了。每袋多算1条，6袋共多算6条；420－6＝414，414＞400，够。仅凭“估大的数超过400”，不能直接断定实际也超过400。

## 第五章　更大的棚，反而不用去

菜园那边终于传来车轮碾过石子的声音。送凳子的车还要绕过一片积水，来得慢些。小美正踮脚望着，放映员递给她一张另一处场地的安排纸。

山脚的大厅也可以放电影。大厅有400个座位，另外两队观众已经在那里等候，每队208人。纸上问：“这两队能不能都安排进大厅？”

【图1】两队各有208人：每队200人 + 8人；两队：200×2 + 8×2。色条示意，不按数量比例。

小美看见“大厅”两个字，差点以为一定更宽敞。她又读了一遍，手指停在“每队208人”上。

她画了两个长条。每条先只画200人，两条已经是400人。可每队还各有8人没有画进去，他们不会因为没画上就消失。

【图2】少算后已到界线：200 + 200 = 400人；实际还有8 + 8人。色条示意，不按数量比例。

“把每队的人数往少了看，已经坐满了。真的人数比400多，不能都安排进去。”小美说。这次，她不用先知道准确有多少人，也能回答纸上的问题。

至于要添多少座位，那是接下来的事：两队各多8人，共多16人。她把“还要16个座位”补在纸角，请送雨衣的人把消息带过去。

【图3】实际在估小数的右边：400 < 416；超过400座，坐不下。位置示意，不按数值比例。

雨渐渐细了。小美看着自己的几张草图，忽然发现，估算并不是把不整齐的数都变漂亮，就算做完了。把数看大了，实际在小的一边；把数看小了，实际在大的一边。还要看那一边，有没有越过要比较的数。

她又想起第一张借凳纸。假如只问座位“大约多少”，把98看成100很方便，因为它离100只差2。可问400人“能不能都坐下”，差的这2个，就不能藏起来了。

> 翻图：208＞200，两队实际人数＞200×2＝400。少算后的数已经到400，实际一定超过400。问“大约多少”和问“够不够”，需要的答案不同。

## 第六章　最后一张坐垫

送凳子的车终于到了。小美把借用纸举得高高的，纸边已经卷起来，那个8却写得清清楚楚。

她和放映员把8把折叠凳搬进棚里，每排补上2把，放在原先空着的位置。四排都成了100个座位。大家重新挪了挪，给中间的通道留出原有的宽度。

【图1】把纸上的差额补回来：392个原有座位 + 8把真凳子；400人都有座位。色条示意，不按数量比例。

最后进来的一位观众收起伞，看见了空着的椅子，松了一口气。小美这才把自己的坐垫铺好。歪歪的小叶子上还有一点湿印，不过靠着棚里的暖风，很快就会干。

银幕展开了。那只蜗牛不知什么时候已经离开，只留下细细的亮线。放映员擦干白布，试了试声音。棚顶上的雨轻了，银幕里却传来一阵更轻的雨——电影里的种子，正等着它。

【图2】四排各补2把：每排98 + 2 = 100；4排共补2×4 = 8把。色条示意，不按数量比例。

第一条细根从土里伸出来时，小美看得很认真。她没有错过。她旁边的人没有站着，后面的人也没有挤在过道里。每个人都有一块稳稳当当的小地方。

她把画着虚线座位的纸折起来，夹在坐垫下面。纸上的八个虚线框没有变成真的椅子，可它们让她发现，究竟缺了什么。

【图3】带走的判断路线：读问句 → 看估大或估小；比较界线 → 必要时修正差额。位置示意，不按数值比例。

电影结束时，雨已经停了。小美帮着收回借来的凳子，在借用纸背面画了一棵小树。树根旁边，她写下三句留给下次的话：

“先听清，是问大约多少，还是问够不够。”

“再看看，我把每一份想大了，还是想小了。”

【图4】原有392座，补上8把真凳子，一共400座；色条不按数量比例。

“拿不准有没有过那条线，就把多想或少想的那一点找回来。”

她没有把那句“大约400”擦掉。它能帮人很快知道座位大约有多少；要让400位观众都坐下，还得看清实际数量与400的关系。
