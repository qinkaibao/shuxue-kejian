# 数学故事创作资料包

这是给**任何大模型或作者**用的公开入口。仓库里没有孩子的姓名、照片、成绩或原卷扫描。读完下列文件后，你就可以自己选题、写故事和配套练习。

站点：https://qinkaibao.github.io/shuxue-kejian/  
本目录在 GitHub：https://github.com/qinkaibao/shuxue-kejian/tree/main/docs  
本说明：[GitHub](https://github.com/qinkaibao/shuxue-kejian/blob/main/docs/README.md) · [raw](https://raw.githubusercontent.com/qinkaibao/shuxue-kejian/main/docs/README.md)

完整清单见 [MANIFEST.md](https://github.com/qinkaibao/shuxue-kejian/blob/main/docs/MANIFEST.md)。

## 然后你可以做什么

- 依据错题线索和教材边界，**自己决定**写哪一个窄主题。
- 直接产出完整故事、真正可数的插图，以及可在手机上操作的练习。
- 对照 [stories/reserved-slugs.json](https://github.com/qinkaibao/shuxue-kejian/blob/main/docs/stories/reserved-slugs.json) 选一个从未用过的 id。

没有人明确要求发布或上线时，不要提交、不要推送、不要覆盖已经上线的故事。先给出本地预览。

## 读数据时请记住

- 路径都是仓库内的相对路径，也可以用上面的 raw 地址直接读取。不要依赖某台机器上的绝对路径。
- 题面是结构重述，不是原卷；原答不是正确答案；旧错不是当前掌握程度。
- 计数已核对：285 个有效编号，308 处位置。网站旧题库只有其中 206 条。
