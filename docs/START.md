# 开写提示

你要为三年级孩子写一篇数学小故事。公开主角叫小美。

1. 读 [WRITING.md](WRITING.md)。故事本身控制在 10 到 15 分钟阅读，之后留大约 5 分钟做配套练习，整体不超过 20 分钟。重点是打开数学思维，而不是把正文写成练习册。字数、章节数和互动题数量都按这个时长设计；正文可先按 2000–3500 字估计，须试读，不要自称已经测过。
2. 打开 [errors/items.json](errors/items.json) 和 [errors/README.md](errors/README.md)，选一条或一组**有原件结构、能自己重算**的线索。跳过 `do_not_grade`、`pending_verification` 里你无法核实的答案。
3. 对照 [stories/INDEX.md](stories/INDEX.md)，不要只换场景重复刚写过的主线（例如：还原被除数、展开图相对面、点段间隔、最小乘数“再退回一份”）。可以从新角度写。
4. 用 [curriculum/grade3-autumn.md](curriculum/grade3-autumn.md) 看印刷页和覆盖边界，不要上传课文扫描或整章原题。
5. 按 [site-conventions.md](site-conventions.md) 做页面和练习。先预览，得到明确的发布许可再上线。

直接开写时，请同时给出：题名与 id、选题依据（题号、自己的重算、教材页）、故事正文、插图和练习。
