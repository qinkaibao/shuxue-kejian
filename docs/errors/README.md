## 怎样读一条记录

- `id` 是匿名题号（如 `M-20261114-263`），只为了追溯同一条整理记录，不是姓名或学号。
- `prompt_abstract` 是**保留数学结构的重述**，不是原卷影印，也不是课文或练习册的逐字转录。
- `recorded_response` 只说明当时写下了什么。它不是正确答案，也不能说明现在会不会。
- `accepted_answer` 与 `answer_status` 要一起看。`recorded_in_source` 表示整理记录里的采用答案；`pending_verification`、`do_not_grade` 表示不要拿来判对错。
- `flags` 和 `evidence_boundary` 写明限度。没有原件时，不要补写没看到的步骤。
- `related_stories` 只在有比较直接的对应时出现，表示“已有一篇可以从这个角度读”，不是“这道题已经掌握”。

## 不能从这里推断的事

- 不要把旧错写成“最近还不会”或“她总是粗心”。
- 同一题另一空曾经做对、后来又改过，只能分条记录，不能折成掌握率。
- 原图、完整表格、作答日期、成绩、回传数据和本地文件路径都没有上传。

## 需要特别小心的编号

- `M-20260910-034`：不要用旧题直接评价。应分开看运算顺序和计算结果；旧答案不可靠。
- `M-20261114-260`：进位数字的计数单位待核，原件未收入。按数位自己重算，不要沿用“5个十”的旧选项。
- `M-20261014-107`：按“一共坐了 6 站……单位是千米”记录的采用答案是 3。若改写成摆了 6 个物体，段数可能变化，必须重算。
