# 三年级上册：单元、页码与覆盖边界

整理者自写。页码指教科书印刷页。本文件不是教材原文。

## 单元与印刷页

| 单元 | 印刷页 | 本批错题线索里的情况 |
|---|---|---|
| 一 观察物体 | 1–5 | 有少量线索（如换位置观察）。展开图、相对面已有故事，不必原样再写一篇。 |
| 二 混合运算 | 6–19 | 有括号、同级与两级运算、看图列式等多条线索。写新题要自己重算顺序和结果。 |
| 三 毫米、分米和千米 | 20–30 | 有长度单位与换算、估测和间隔类线索。改写点段或“坐了几站”时必须按新题面重算。 |
| 综合与实践 曹冲称象的故事 | 31–38 | 有质量单位线索。 |
| 四 多位数乘一位数 | 39–56 | 线索最多。已有进位、补 0、最小乘数等故事，新作要找尚未写成主线的窄问题，或换一个真正不同的决定。 |
| 综合与实践 数字编码 | 57–60 | 有邮政编码、固定位段、取件码、运动员号码和由日期判断年龄的线索。 |
| 五 线和角 | 61–72 | 新增过两点画直线的线索，注意直线和线段的区别。 |
| 六 分数的初步认识 | 73–91 | 同上。 |
| 七 复习与关联 | 92–103 | 复习位置，不要把复习页里的题冒充本单元例题。 |

## 第四单元内部（只记结构，不抄原题）

- 印 p40：口算乘法（整十、两位数乘一位数）。
- 印 p43–45：笔算不进位、一次进位、连续进位。
- 印 p49–50：有 0 的乘法，中间有 0、末尾有 0。
- 印 p51：用估算解决问题。
- 印 p52–54：练习十（比较数量、乘数与积的表格等）。
- 印 p55–56：整理和复习。

## 覆盖边界

- 本资料包的多数错题线索落在第一至第四单元及质量综合实践，也已收录数字编码和线与角的少量线索。
- “没有某单元的错题记录”不等于“已经会了”，只说明这里没有据此写新篇的近期证据。
- 教材例题的具体数字、插图对话和练习题原文请在合法文本中阅读，不要从本仓库还原整章。
