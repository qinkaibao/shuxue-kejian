# Agent guide

This repository is a Grade 3 Chinese math-story site: https://qinkaibao.github.io/shuxue-kejian/

If you are asked to write a new math story, start with the public writing kit (relative paths; also readable via raw.githubusercontent.com):

1. [docs/START.md](docs/START.md)
2. [docs/WRITING.md](docs/WRITING.md)
3. [docs/errors/README.md](docs/errors/README.md) and [docs/errors/items.json](docs/errors/items.json)
4. [docs/stories/INDEX.md](docs/stories/INDEX.md)
5. [docs/curriculum/README.md](docs/curriculum/README.md)
6. [docs/site-conventions.md](docs/site-conventions.md)
7. [docs/errata-status.md](docs/errata-status.md)

Kit index: [docs/README.md](docs/README.md)

Rules in short: about 20 minutes of story reading (estimate, not a measured claim), focus on mathematical thinking, no real names/photos/scores, do not republish textbook scans, do not auto-publish without an explicit request, do not reuse reserved slugs, do not modify `common/*.js` or existing stories unless asked.
